# 지텔프 65 작전 (G-TELP-master)

지텔프 Level 2 **65점**을 2027년 2월 말까지 받기 위한 공부 앱입니다. 휴대폰 브라우저에서 열고 "홈 화면에 추가"하면 앱처럼 쓸 수 있어요.

## 작전: 문법으로 점수를 번다
총점은 세 영역 점수의 평균입니다. 문법 24/26(92) + 독해 17/28(61) + 청취 11/26(42) = **평균 65**.

| 탭 | 내용 |
|---|---|
| 오늘 | D-day, 오늘의 미션 4개(문법 20 · 단어 30 · 독해/청취 1세트 · 오답), 14주 로드맵 중 지금 단계, 가장 약한 유형 |
| 문법 | 7유형 공식 카드 · 유형별 연습(89문제) · 실전 26문항(시험 비율·시간 재기) · 오답노트 · -ing/to V 동사 퀴즈 · 시제 단서 표 |
| 독해·어휘 | 파트별 지문 4개(인물·잡지·백과·편지) × 7문항 + 근거 해설 · 단어 카드 181개(간격 반복) · 동의어 퀴즈 |
| 청취 | 파트별 4세트, 기기 영어 음성으로 "질문 → 본문 → 질문" 실전 순서로 읽어 줌 · 속도 조절 · 대본 |
| 점수 | 점수 계산기 · 모의고사/실제 시험 기록과 65점 선 그래프 · 문법 유형별 정답률 |

기록은 그 기기의 브라우저(localStorage)에만 저장됩니다.

## 고치기
```
src/data.js   ← 문법 문제, 단어, 독해 지문, 청취 대본, 로드맵 (원본)
src/app.html  ← 화면과 동작
python3 tools/build.py  → index.html (바로 열기·GitHub Pages) + dist/app.html
```
문제와 지문은 모두 이 앱용으로 직접 쓴 연습 문항입니다.
