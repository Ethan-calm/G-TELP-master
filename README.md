# 지텔프 65 작전 (G-TELP-master)

지텔프 Level 2 **65점**을 **7일 완성**으로 받기 위한 공부 앱입니다 (최종 마감 2027년 2월 말). 휴대폰 브라우저에서 열고 "홈 화면에 추가"하면 앱처럼 쓸 수 있어요.

## 작전: 문법으로 점수를 번다
총점은 세 영역 점수의 평균입니다. 문법 24/26(92) + 독해 17/28(61) + 청취 11/26(42) = **평균 65**.

| 탭 | 내용 |
|---|---|
| 7일 | D-day, 7일 계획 전체(날마다 시간표·목표·완료 체크), 65점 공식, 가장 약한 유형 |
| 요약 | 시험 전날 한 장: 시제 단서표, 가정법, 동사 뒤 모양, 당위성·조동사, 관계사·연결어, 독해·청취 전략, 시험 당일 |
| 문법 | 148문제(기출 경향 반영 긴 문장 포함)를 유형별로 한 화면에 펼쳐 풀기 · 실전 26문항(시험 비율·시간) · 오답노트 · 동사 뒤 모양 퀴즈 |
| 독해 | 8지문(2회분) × 7문항, 넓은 화면에선 지문과 문제를 나란히 · 정답 근거 해설 |
| 어휘 | 181개 전체 표 (뜻 가리기·외움 체크·Day별 구간) · 동의어 퀴즈 30 |
| 청취 | 8세트(2회분, 7·6·6·7문항) · 기기 영어 음성으로 질문→본문→질문 순서 |
| 모의 | 실전 구성 모의고사 2회(문법 26 · 청취 26 · 독해 28) 한 페이지, 고른 답 자동 저장, 채점·기록 · 점수 계산기 · 그래프 |

기록은 그 기기의 브라우저(localStorage)에만 저장됩니다.

## 고치기
```
src/data.js   ← 문법 문제, 단어, 독해 지문, 청취 대본, 로드맵 (원본)
src/app.html  ← 화면과 동작
python3 tools/build.py  → index.html (바로 열기·GitHub Pages) + dist/app.html
```
문제와 지문은 모두 이 앱용으로 직접 쓴 연습 문항입니다.
